# Checkmate

Checkmate is a browser-based two-player chess game made with HTML, CSS, and JavaScript.

## Play the game

You can play the game online here:

[Play Checkmate](https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/ )

Replace the link above with your real GitHub Pages link after you enable GitHub Pages.

## Features

- Two-player local chess
- Legal chess moves
- Check and checkmate
- Stalemate detection
- Castling
- En passant
- Pawn promotion
- Undo button
- Move history
- Responsive design for smaller screens

## How to play

Click a chess piece to select it
Highlighted squares show where the piece can legally move
Click a highlighted square to move
White starts first
